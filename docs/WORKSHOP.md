# Build Your Digital Twin

From scattered context to a living AI system.

In this workshop, you'll build a personal Digital Twin using Claude Code.

We'll build it step-by-step together:
1. Add your raw context
2. Understand what the AI knows about you
3. Structure that context into persistent knowledge
4. Define how your Twin should behave
5. Build a personalized workflow
6. Test and improve it
7. Create a system for adding new information

## Before We Start

Do not build ahead — we'll create the system together.

Put the files you brought for the workshop inside `/inbox`.

Then open this repository in Terminal and run:

`claude`
